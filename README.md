# Smarter Spaces Solutions
*Maker the space a better world*

**English** / [简体中文](./README.zh-CN.md)

Smarter Spaces Solutions is an open-source, hardware-grounded, scenario-driven community. Focused on real-world scenarios such as elder care, child-friendly environments, and animal welfare, it uses Seeed's hardware capabilities to co-create deployable smart-space solutions.

![avatar](https://github.com/Seeed-Studio/Smarter-Spaces-Solutions/blob/main/flowchart.png?raw=true)

</div>

## What this is

The project translates [Seeed Studio](https://www.seeedstudio.com/)'s hardware ecosystem (XIAO / SenseCAP / Grove / reTerminal / SenseCAP Watcher, etc.) into solutions that can be sensed and deployed in real social spaces, while feeding real-world needs back to the hardware product teams:

```
Seeed hardware ecosystem  →  Smarter Spaces Solutions (Issue-driven co-creation)  →  Real-world spaces
(provides hardware capability)                                                    (elder care facilities / child-friendly spaces / animal shelters / public spaces)
```

Solutions can also be deployed onto the [Chaihuo MCV](https://github.com/Chaihuo-Makerspace/chaihuo-mcv-site) ([mcv.chaihuo.org](https://mcv.chaihuo.org)) — a mobile AI lab touring China for 200 days, testing solutions in real, extreme environments and co-creating with local residents.

## How to participate

Collaboration happens through Issues: anyone interested in Smarter Spaces Solutions can participate — no predefined role required.

- **Claim a task**: browse Issues labeled [`type:need`](../../labels/type%3Aneed) + [`status:open`](../../labels/status%3Aopen), then comment to claim one.
- **Pitch an idea**: have a scenario idea or solution concept? [Open an issue](../../issues/new/choose) with the `type:proposal` template.
- **Report a problem**: found a bug or a documentation issue? Use the `bug` template.
- **Just want to talk**: unformed ideas, looking for collaborators, or sharing experience — head to [Discussions](../../discussions).
