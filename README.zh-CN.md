# Smarter Spaces Solutions
*Maker the space a better world*

[English](./README.md) / **简体中文**

Smarter Spaces Solutions 是一个以硬件为载体、以场景为驱动的开源共创社区，专注于养老、儿童友好环境和动物福利等真实空间场景，用 Seeed 的硬件能力共同打造可落地的智能空间解决方案。

![avatar](https://github.com/Seeed-Studio/Smarter-Spaces-Solutions/blob/main/flowchart.png?raw=true)

</div>

## 这是什么

项目把 [Seeed Studio](https://www.seeedstudio.com/) 的硬件生态（XIAO / SenseCAP / Grove / reTerminal / SenseCAP Watcher 等）翻译成社会场景中可感知、可部署的解决方案，同时把场景中的真实需求反哺给硬件产品团队：

```
Seeed 硬件生态  →  Smarter Spaces Solutions（Issue 驱动共创）  →  真实空间场景
（提供硬件能力）                                              （养老机构 / 儿童活动空间 / 动物救助站 / 社区公共空间）
```

方案还可以进一步部署到 [柴火基地车](https://github.com/Chaihuo-Makerspace/chaihuo-mcv-site)（[mcv.chaihuo.org](https://mcv.chaihuo.org)）—— 一辆巡回中国 200 天的移动 AI 实验室，在真实、极限环境中检验方案，并与在地居民共创迭代。

## 如何参与

协作围绕 Issue 展开：任何对 Smarter Spaces Solutions 感兴趣的人都可以参与，不需要预先归类身份。

- **认领一个任务**：浏览带有 [`type:need`](../../labels/type%3Aneed) + [`status:open`](../../labels/status%3Aopen) 标签的 [Issues](../../issues)，在评论区认领即可开始。
- **提一个想法**：如果你有场景创意或解决方案思路，用 `type:proposal` 模板 [提交 Issue](../../issues/new/choose)。
- **报告问题**：发现 Bug 或文档错误，用 `bug` 模板提交。
- **随便聊聊**：还没想清楚的点子、找搭子、经验分享，欢迎去 [Discussions](../../discussions)。

## 场景领域

项目目前聚焦三个场景，对应仓库的 `area:*` 标签：

- [`area:elder-care`](../../labels/area%3Aelder-care) — 养老
- [`area:child-friendly`](../../labels/area%3Achild-friendly) — 儿童友好环境
- [`area:animal-welfare`](../../labels/area%3Aanimal-welfare) — 动物福利

## 案例研究

`case_study/` 目录收录与项目方向相关的学术研究、商业方案与社区实践，为解决方案提供参考和灵感。
